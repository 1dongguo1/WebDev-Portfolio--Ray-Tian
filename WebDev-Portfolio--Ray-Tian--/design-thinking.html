My Design Thinking Process

1

Empathize

Understanding user needs through research and interviews. For example, when developing this portfolio website, I first analyzed the expectations and needs of potential visitors, such as clear navigation and engaging visuals.

2

Define

Based on user research, identifying core problems and design goals. I determined key features to showcase, such as project displays, skill introductions, and accessibility considerations.

3

Ideate

Brainstorming multiple solutions to enhance user experience. I explored various layouts, interaction patterns, and visual designs to create an intuitive and aesthetically pleasing website.

4

Prototype

Creating interactive prototypes using tools like Figma to visualize ideas. Low-fidelity prototypes were developed to validate concepts quickly before coding the final website.

5

Test

Collecting user feedback through usability testing and iterating based on results. I ensured the website is accessible, responsive, and user-friendly across devices.
