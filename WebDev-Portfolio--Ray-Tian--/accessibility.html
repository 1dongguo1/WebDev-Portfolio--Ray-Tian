Accessibility Features

Our commitment to making the web accessible to everyone.

Keyboard Navigation

Our website supports full keyboard navigation:

  • Use Tab key to navigate through all interactive elements
  • Enter key to activate links and buttons
  • Space key to toggle audio playback
  • Arrow keys for additional navigation options

Screen Reader Support

We ensure compatibility with screen readers:

  • All images have descriptive alt text
  • Proper heading hierarchy for content structure
  • ARIA labels where necessary
  • Semantic HTML elements

Visual Accessibility

Features to support users with visual impairments:

  • High contrast text and backgrounds
  • Resizable text without breaking layout
  • Clear focus indicators
  • Consistent navigation structure

Audio Features

Audio accessibility features:

  • Background music can be toggled with spacebar
  • Visual feedback for audio controls
  • Volume control available
  • Audio visualizer for visual feedback
