AES Encrypt/Decrypt Tool

A C++ tool for AES-256 encryption and decryption based on OpenSSL

Project Overview

This project is a C++ tool for AES-256 encryption and decryption, implemented with the OpenSSL library. It supports Base64 encoding for output, making it suitable for secure communication and data protection scenarios.

Main Features

  • Supports AES-256-CBC mode encryption and decryption
  • Automatic Base64 encoding for encrypted results
  • Automatic Base64 decoding for decryption
  • Exception handling and error messages

Tech Stack

  • C++
  • OpenSSL
